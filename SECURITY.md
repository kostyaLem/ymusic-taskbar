# Security

The application uses local Windows media and audio controls. It does not require a music account token or upload listening data.

Do not include account data or access tokens in public reports. Diagnostic files can contain track names and local paths; review them before sharing.

For a suspected vulnerability, use GitHub private vulnerability reporting if available, or contact the repository owner privately through an available GitHub contact.

The bundled .NET runtime is updated with application releases. Builds are currently unsigned; obtain downloads from this repository and compare the supplied checksums.
