# Third-party components

The project's own code and vector / icon assets are covered by the root MIT license.

- **.NET and Windows Desktop runtime** — Microsoft / .NET contributors. The self-contained distribution includes runtime license and third-party notice files supplied by the runtime packages. Source and terms: https://github.com/dotnet/runtime and https://github.com/dotnet/wpf.
- **C#/WinRT runtime / Windows SDK projection** — Microsoft. Used by the Windows media-session adapter. The C#/WinRT MIT license is included in `legal/CsWinRT-LICENSE.txt`. Source: https://github.com/microsoft/CsWinRT. Windows SDK targeting-pack terms: https://aka.ms/WinSDKLicenseURL.
- **Inno Setup** — Jordan Russell, Martijn Laan and contributors. Used to build the installer. The compiler is downloaded separately into `.tools` and is not shipped in the source archive. See https://jrsoftware.org and its license / commercial-use terms.
- **GitHub Actions** — official `actions` repository actions used in CI. Their source and licenses remain with the corresponding repositories.

The application is an unofficial companion. The project icon is an original asset.
