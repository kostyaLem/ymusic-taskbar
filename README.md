# YMusic Taskbar

<img src="assets/app.png" width="64" height="64" alt="Значок YMusic Taskbar">

**Неофициальный мини-плеер для Яндекс Музыки** на панели задач Windows 10 / 11. Управляйте музыкой рядом с кнопками приложений, не открывая основное окно.

[English](README.en.md) · [Инструкция](USAGE.md) · [Скачать](https://github.com/kostyaLem/ymusic-taskbar/releases) · [MIT](LICENSE)

*Крупный план плеера. Его фон прозрачный; в приложении он занимает свободную область панели задач.*

## Возможности

- Обложка, исполнитель и название трека.
- Воспроизведение, пауза, переключение треков и перемотка.
- Громкость и выключение звука.
- Полный и компактный режимы; светлая, тёмная и системная темы.
- Свои сторона и вид плеера для каждого экрана, необязательный автозапуск.

Все параметры находятся в **⋯ → Настройки…**. Это же окно открывается через значок в трее. Плеер подстраивается под свободное место и переносится с экрана, занятого полноэкранным приложением.

## Системные требования

- **Windows 10 22H2 или Windows 11, x64.**
- **Около 200 МБ** на диске.
- **.NET 10 Desktop Runtime x64** (версия 10.0.11 включена в установщик и portable-архив).

## Скачать и установить

Один установщик подходит для обеих ОС. Готовые выпуски размещаются в **[Releases](https://github.com/kostyaLem/ymusic-taskbar/releases)**. Установите `YMusicTaskbar-0.5.0-win-x64-Setup.exe`, включите трек в музыкальном приложении и запустите мини-плеер из меню «Пуск». Права администратора не нужны.

Для запуска без установки распакуйте **весь** portable-архив и откройте `YMusicTaskbar.exe`.

Если релиз ещё не опубликован, свежую сборку можно скачать из последнего успешного запуска **[сборки приложения](https://github.com/kostyaLem/ymusic-taskbar/actions/workflows/build.yml)**: раздел **Artifacts → YMusicTaskbar-windows** (нужен вход в GitHub).

Установщик пока без цифровой подписи; Windows может показать предупреждение неизвестного издателя. Контрольные суммы находятся в `SHA256SUMS.txt`.
